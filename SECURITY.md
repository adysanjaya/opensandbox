## Reporting a Vulnerability

The OpenSandbox team takes security seriously. If you discover a security vulnerability, please do **NOT** open a public GitHub issue.

Instead, please report the vulnerability privately via email:

- **Security Contact:** [adysanjaya013@gmail.com](mailto:adysanjaya013@gmail.com)
- **Subject:** `[SECURITY] Vulnerability in OpenSandbox`

Please include the following information:
1. Type of vulnerability (e.g. SQL Injection, XSS, SSRF, Auth bypass)
2. Step-by-step instructions to reproduce the issue
3. Proof-of-concept (PoC) code or requests if available
4. Any suggested fix or remediation

### Response Timeline
- We will acknowledge receipt within **48 hours**.
- We will assess the impact and provide a status update or fix timeline within **7 business days**.
- Once a fix is verified and deployed, we will publish an advisory and credit the reporter.

Thank you for practicing responsible disclosure and keeping the community secure!
